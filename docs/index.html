像素G PixG

AI 圖片精準輸出

協助 Web ChatGPT 使用者以目標比例生成圖片，並在瀏覽器本機將圖片裁切、縮放、轉換與驗證為真正指定的像素尺寸。

PixG 解決什麼問題？

在 ChatGPT 提示詞中輸入 800×600、1920×1080 等尺寸，通常只能影響構圖比例，不保證下載檔案的實際像素就是該尺寸。PixG 把「生成比例」與「精準像素輸出」分成兩個步驟處理。

主要功能

  • 只辨識目標寬高與比例，不改寫你的內容、風格、人物或背景需求。
  • ChatGPT 圖片 hover / 右鍵一鍵進入精準輸出。
  • 單一所見即所得預覽。
  • Cover / Contain / Stretch、九宮格位置與拖曳式手動裁切。
  • 手動裁切確認後可一鍵「裁切還原」。
  • 畫布可使用透明棋盤格、淺灰、白、深色或自訂色，方便檢查透明輸出。
  • 自動去除透明或純色空白邊界。
  • 下載前可直接自訂檔案名稱，副檔名依 PNG / JPEG / WebP 自動加入。
  • PNG / JPEG / WebP，下載前重新驗證實際像素與格式。
  • 圖片處理在瀏覽器本機完成，不需要 OpenAI API Key。

資料與隱私

PixG 沒有自有後端服務，不會把你的圖片或提示詞傳送到 PixG 伺服器。詳細內容請查看隱私權政策。
