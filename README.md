# PixG｜像素G

PixG 協助 Web ChatGPT 依你指定的尺寸比例生成圖片，並在瀏覽器本機將圖片裁切、縮放、轉換與驗證為真正指定的像素尺寸。

## 🚀 下載最新版

👉 **[前往 GitHub Releases 下載 PixG](https://github.com/index7777/PixGauge/releases/latest)**

一般使用者請下載：

**`PixG-v1.7.3-store.zip`**

> 請不要把 GitHub 頁面上方的 **Code → Download ZIP** 當成安裝包；那是整個儲存庫的原始碼。

## Chrome 手動安裝

1. 從 Releases 下載 `PixG-v1.7.3-store.zip`
2. 將 ZIP 解壓縮
3. Chrome 開啟 `chrome://extensions/`
4. 開啟右上角「開發人員模式」
5. 點「載入未封裝項目」
6. 選擇剛解壓縮、裡面含 `manifest.json` 的資料夾
7. 開啟或重新整理 `https://chatgpt.com/`

完成後，ChatGPT 頁面會出現 PixG 浮動按鈕。

> GitHub 版本需要以「開發人員模式」手動載入。Chrome Web Store 正式版上架後，一般使用者可直接一鍵安裝。

## 功能

- Web ChatGPT 只解析目標尺寸與比例，不改內容 prompt
- 精準像素輸出
- Cover / Contain / Stretch
- 所見即所得預覽
- 九宮格與手動裁切
- 自動去空白
- 透明畫布
- PNG / JPEG / WebP
- 自訂下載檔名
- 下載前重新驗證 width / height / format
- 不需要 OpenAI API Key
