# PixG｜像素G

目前版本：**v1.6.1**

PixG 是一個 Chrome Manifest V3 擴充功能，協助 Web ChatGPT 依目標比例生成圖片，並在瀏覽器本機裁切、縮放、轉換與驗證為真正指定的像素尺寸。

## 官方頁面

- 產品 / Listing：https://index7777.github.io/PixGauge/
- 隱私權政策：https://index7777.github.io/PixGauge/privacy.html
- 支援 / Issues：https://github.com/index7777/PixGauge/issues
- 隱私權政策原始文件：https://github.com/index7777/PixGauge/blob/main/PRIVACY.md

Chrome Web Store 的 Privacy Policy URL ：

`https://index7777.github.io/PixGauge/privacy.html`

GitHub Pages 的內容放在 `docs/`，並已加入自動部署 workflow。儲存庫第一次啟用 Pages 時，需要在 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**；之後 `docs/` 更新會自動部署。

PixG 不需要 OpenAI API Key；圖片後處理在使用者瀏覽器本機完成。擴充功能內也能直接開啟「產品資訊」與「隱私權政策」。

> PixG（像素G）為獨立開發的 Chrome 擴充功能，非 OpenAI 官方產品。
